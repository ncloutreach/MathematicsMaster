1.If the rabbit starts at 0 and hops onto a stone marked –5, what is the new position?

A. –10

B. +5

C. –5

D. 0

 Answer: C. –5




2. The rabbit hops on stones with values +8 and –3. What is the total position now?

A. +5

B. +11

C. –11

D. –5

 Answer: A
(Because +8 + (–3) = +5)




3.If the path to a stone is A + B + C, where A = –4, B = +4, C = –11, what is the total?

A. –15

B. –11

C. –10

D. –7

 Answer: B. –11

   −4+4=0-4 + 4 = 0−4+4=0
   0+(−11)=−110 + (-11) = -110+(−11)=−11
   Total = –11





4. A green-colored stone shows the expression 2A + 3B, where A = –2 and B = +6. What is the answer?

A. +14

B. +10

C. –10

D. +18

 Answer: A
(Because 2×–2 + 3×6 = –4 + 18 = +14)




5.Which of the following shows that the rabbit returns to the starting point (0)?

A. +4 + (–4)

B. +3 + (+3)

C. –5 + (–5)

D. +2 + (+1)

 Answer: A
(Because +4 + –4 = 0)
